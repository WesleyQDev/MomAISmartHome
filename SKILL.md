# MomAI Smart Home Skill

Esta skill permite ao assistente MomAI consultar e controlar dispositivos de casa inteligente localmente.

## Ferramentas Disponíveis
- `init`: Inicializa o banco de dados e verifica a sessão.
- `login`: Abre o fluxo Google OAuth 2.0 para autenticação.
- `listDevices`: Lista os dispositivos conectados.
- `turnOn`: Liga um dispositivo.
- `turnOff`: Desliga um dispositivo.
